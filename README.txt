NIGHTCHAT - LOCAL REAL-TIME CHAT

Requirements:
- Node.js installed on your computer
- Internet is NOT required after the dependency is installed

SETUP

1. Open a terminal in this folder.

2. Install the WebSocket package:
   npm install

3. Start the server:
   npm start

4. Open this address in your browser:
   http://localhost:8080

5. Enter a username and join.

TESTING MULTIPLE USERS

Open http://localhost:8080 in two browser tabs/windows.
Use a different username in each.
Messages sent in one window will appear in the other.

IMPORTANT

This is a local/demo chat application.
It does NOT have:
- user accounts
- database storage
- message history after restart
- end-to-end encryption
- moderation
- production authentication

The server listens on port 8080.
